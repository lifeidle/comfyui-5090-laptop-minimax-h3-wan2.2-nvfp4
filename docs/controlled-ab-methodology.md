# 量化对比的受控实验方法

> 配套：[English](controlled-ab-methodology.en.md) · 数据见 [`../data/quant-ab-metrics.md`](../data/quant-ab-metrics.md) · 工具见 [`../tools/ab_metrics.py`](../tools/ab_metrics.py)

本文把"如何判断一个量化格式有没有掉画质"这件事讲透。它不是理论推导，是**我们先用错方法得出错误结论、
再修正**的完整记录。

---

## 一、为什么直觉会骗你

第一轮我们跑了两个 Z-Image-Turbo 变体，量出 PSNR = 13.82 dB，于是下结论："4-bit 量化掉画质。"

**错在哪？两个变体用了不同的文本编码器。**

- int8 版配 `qwen_3_4b.safetensors`（bf16）
- nvfp4 版配 `qwen_3_4b_fp4_mixed.safetensors`（fp4）

编码器的差异被混进了那个 13.82 dB 里。我们测量的是"编码器 + 量化"的合成效应，却把结论归给了量化。

> **教训一：一次只能动一个变量。编码器、提示词、分辨率、步数、采样器、CFG、种子
> —— 除了要测的那个，其余全部必须固定。**

---

## 二、为什么 PSNR 本身也不够用

就算把变量控干净了，还有一个更深的问题：

> **扩散采样是混沌的。**

两个权重值前 4 位完全相同的模型，经过 8 步采样会产出**构图完全不同的两张图**。
原因是采样过程会持续放大微小差异 —— 这是生成模型的本性，不是缺陷。

后果很严重：

| 你观察到的 | 你能得出的结论 |
|---|---|
| 两张图 PSNR = 16 dB | 它们是两个不同的样本 |
| 两张图 PSNR = 16 dB | ❌ **不能**得出"其中一张质量更差" |

所以 PSNR 本身**无法回答**"量化有没有损伤画质"。它缺一个参照系。

> **教训二：必须引入噪声基线 —— "同一量化、只换随机种子"造成的差异。
> 只有把量化差异和种子差异放在一起比，PSNR 才有意义。**

---

## 三、四组对照的设计

核心思路：把"量化扰动"和"采样随机性"分离成两个可比的量。

| 组 | 固定什么 | 变什么 | 目的 |
|---|---|---|---|
| **det** | 全部 | **什么都不变**（重跑） | 确定性检验 |
| **seed** | 全部 + 量化 A | 只变随机种子 | 噪声地板 |
| **cross** | 全部 + 固定种子 | **只变量化格式** | 被测量对象 |
| **seedB** | 全部 + 量化 B | 只变随机种子 | 噪声地板（第二份） |

**判据：**

```
cross 相似度 ≥ seed 相似度   →  量化扰动 ≤ 采样噪声  →  量化可忽略
cross 相似度 ≪ seed 相似度   →  量化引入了超出噪声的失真
```

### `det` 组为什么不能省

`det` 组若不等于 ∞（不是逐字节一致），说明**管线本身不可复现**。那么 `cross` 组的差异就
既可能来自量化、也可能来自运行时波动 —— **无法归因，整个实验作废**。

我们先测 `det`，得到 ∞，才敢继续。

---

## 四、实测结果

| 对比组 | 变量 | PSNR | 平均像素差 |
|---|---|---|---|
| **det** 同量化同种子重跑 | 无 | **∞ dB** | **0.00%** |
| **seed** int8 换种子 | 只变种子 | 12.10 dB | 16.89% |
| **cross** nvfp4 vs int8（同种子） | **只变量化** | **16.84 dB** | **7.41%** |
| **seedB** nvfp4 换种子 | 只变种子 | 12.45 dB | 16.43% |

**7.41% < 16.89%** —— 换量化格式对画面的改变，**比换个随机种子还小**。

---

## 五、为什么不能只看 PSNR：加 5 个鲁棒指标

PSNR 对轨迹分叉敏感，所以我们同时测**不受分叉影响**的质量代理：

| 指标 | 定义 | 它回答什么 |
|---|---|---|
| 锐度 | Laplacian 响应方差 | 细节有没有丢（糊了） |
| 香农熵 | 灰度直方图的信息熵 | 信息量有没有下降 |
| 高频能量比 | `mean(‖img−blur‖) / std(img)` | 细节保留程度 |
| 颜色直方图 L1 | 三通道分布距离 | 色调有没有系统性偏移 |
| 分区 PSNR | 4×4 网格各自算 PSNR | 差异是**分布式的**还是**局部集中的** |

实测：

| 样本 | 锐度 | 熵 | 高频比 |
|---|---|---|---|
| int8 · 种子 A | 776.5 | 5.572 | 0.0130 |
| int8 · 种子 A（重跑） | 776.5 | 5.572 | 0.0130 |
| int8 · 种子 B | 705.4 | 5.736 | 0.0134 |
| nvfp4 · 种子 A | 694.3 | 5.614 | 0.0127 |
| nvfp4 · 种子 B | 604.1 | 5.791 | 0.0140 |

两个关键读法：

1. **重跑那一行与基准完全一致**（776.5 / 5.572 / 0.0130）—— 和 `det` 组 PSNR = ∞ 互相印证，管线确实确定性。
2. **同量化内部的种子波动（776.5 → 705.4，−71.1）已经覆盖了跨量化的差异（776.5 → 694.3，−82.2）。**
   两个量级相同 → 量化不是可区分的因素。

分区 PSNR 也支持这个判断 —— 4×4 网格里没有任何一格塌陷到接近 0：

```
 18.8  35.9  33.5  28.2
 14.2  17.7  15.7  16.2
 15.3  11.3  18.3  13.7
 25.1  18.1  18.2  18.2
```

> 如果是**结构化伪影**（比如某种量化的块效应），差异会集中在特定区域，出现个别极低的格子。
> 分布式差异才是"采样轨迹分叉"的表现。

## 六、最后一道：人眼复核

把四张图按 **2×2** 摆，并且**刻意按"竖看=同种子跨量化、横看=同量化换种子"**排列：

```
┌──────────────────────┬──────────────────────┐
│  INT8  · seed 20260922│  INT8  · seed 20260923│
├──────────────────────┼──────────────────────┤
│ NVFP4  · seed 20260922│ NVFP4  · seed 20260923│
└──────────────────────┴──────────────────────┘
   竖列 → 同种子、跨量化      横行 → 同量化、跨种子
```

结果：**竖列构图高度相似，横行构图完全不同。** 视觉结论与全部数字一致。

> 这个排列本身是方法论的一部分 —— 一张图同时呈现两组对照，比看两两对比更直观。

## 七、可以直接复用的检查清单

做任何"量化是否掉画质"的对比之前，逐条确认：

- [ ] 编码器、提示词、分辨率、步数、采样器、CFG **全部固定**
- [ ] 只改变量化格式这一个变量
- [ ] 跑了 `det` 组，确认重跑是逐字节一致的（否则先解决确定性）
- [ ] 跑了 `seed` / `seedB` 组，拿到噪声地板
- [ ] `cross` 的 PSNR 与 `seed` 在同一量级或更高
- [ ] 质量代理指标（锐度/熵/高频/色彩）无系统差异
- [ ] 分区 PSNR 无局部塌陷（排除结构化伪影）
- [ ] 四联图人眼复核通过

八条全过，才能说"量化没有掉画质"。

---

## 八、这套方法的适用边界

**适用**：图像 / 视频 / 音频等一切扩散或自回归生成模型的量化、量化版本选择、
蒸馏 LoRA 保真度评估、模型微调前后的差异归因。

**不适用**：判别模型、分类器、超分等**输出对输入连续且确定**的任务 ——
那些场景 PSNR 可以直接用，不需要噪声地板。

**一句话总结**：**PSNR 是测量工具，噪声基线是标尺。没有标尺，测出来的数不能读。**
